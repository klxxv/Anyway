# Compatibility prompt root

The version-controlled PDF Agent source lives at
[`my-plugins/anPdfsolver`](../../../my-plugins/anPdfsolver). This directory
only keeps a prompt mirror for the current Rust Host baseline, whose protected
loader still resolves `plugins/sources/myc.pdf-canvas-agent/prompts`. It is not
a development or package-discovery root and must not be edited as the source
of truth.
